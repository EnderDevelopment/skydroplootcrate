# SkyDropLootCrate

SkyDropLootCrate is a Minecraft mod built with EnderDevelopment.

## About

Create a new Minecraft item. Appearance: Blue Fortnite looking crate that leaves blue smoke like trail while its falling from the sky, like in Fortnite. Behavior: i want the mod to drop a loot crate with good weapons every 5th ingame day. in the chat a message saying a loot drop landed and it shows the coordinates, so people have to race to get the loot drop. make it like a blue drop like the ones
